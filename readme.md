# ESP32 기반 심박 측정 키트

![ESP32-DevkitC V4](docs/images/esp32-devkitc-v4.jpg)

이 프로젝트는 **ESP32-DevkitC V4** 보드와 심박 센서를 이용해 심박수를 측정하고,
1.3인치 OLED 디스플레이에 표시하는 예제입니다.  
패시브 부저, 버튼, LED를 이용해 알림 기능과 UI 조작도 가능합니다.  

하드웨어 설계와 아두이노 소스코드를 모두 제공합니다.

---

## 📦 하드웨어 구성

| 부품명                | 설명 |
|----------------------|------|
| ESP32-DevkitC V4     | 메인 컨트롤러 |
| 1.3인치 OLED (I2C)   | 심박수 표시 |
| 심박 센서 (기본: MAX30100) | I2C 기반 심박/산소포화도 측정 |
| 심박 센서 (옵션: XD-58C)   | 아날로그 출력 기반 심박 측정 |
| 패시브 부저          | 심박 알림 및 경고음 |
| 버튼 4개              | 메뉴, 시작/정지, 설정 조작 |
| LED 2개 (GPIO 제어)  | 상태 표시 |

---

## 🔌 핀 연결 (기본 MAX30100 사용 시)

| ESP32 핀 | 기능 | 연결 부품 |
|----------|------|-----------|
| 3V3      | 전원 | OLED, 센서 |
| GND      | GND  | OLED, 센서 |
| GPIO 21  | I2C1 SDA | OLED |
| GPIO 22  | I2C1 SCL | OLED |
| GPIO 16  | I2C2 SDA | MAX30100 |
| GPIO 17  | I2C2 SCL | MAX30100 |
| GPIO 36  | 버튼 1 |
| GPIO 39  | 버튼 2 |
| GPIO 34  | 버튼 3 |
| GPIO 35  | 버튼 4 |
| GPIO 5   | 부저 (PWM) |
| GPIO 25  | LED1 제어 |
| GPIO 26  | LED2 제어 |

※ XD-58C 사용 시 아날로그 입력 핀 예: GPIO 36(ADC1_CH0) 로 변경 가능.
